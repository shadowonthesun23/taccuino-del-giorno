# Day Atlas audio assets

The audio engine uses only selected, licensed assets. Unavailable sounds stay disabled in `lib/audio-config.ts`.

| Suggested file | Format | Ideal duration | Character | Loop | Relative level |
| --- | --- | ---: | --- | --- | ---: |
| `home-ambient-jazz.mp3` | MP3, stereo | Selected asset | Quiet ambient/jazz music | Yes | 0.08 |
| `postcard-paper.mp3` | MP3, stereo | Selected asset | One restrained paper/card interaction shared by postcard and ticket | No | 0.045 |
| `postcard-flip-soft.mp3` | MP3, stereo | 0.504 s | Soft front/back card turn | No | 0.035 |

The existing `museum-gallery-ambience.mp3` remains the museum source. Day-change audio is intentionally disabled in V1 and has no UI trigger.
